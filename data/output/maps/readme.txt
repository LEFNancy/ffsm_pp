This directory contain the FFSM++ exported maps as well a "Gis data directory" of Grass, a very well-know open-source GIS (http://grass.itc.it). It includes also a shell script for easy import of maps into Grass.

If you are under Linux, after having ran FFSM++ just cd to this directory and type ./importInGrass.sh to import the maps, their category classification and their colours to Grass.
