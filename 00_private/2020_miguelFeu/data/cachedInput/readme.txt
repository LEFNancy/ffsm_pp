In order to speed it up the loading of the input variables you can save here two files, forData.csv and prodData.csv.
If the program find here these two files, it will use them instead of the equivalent (big) tables for the openoffice file.
For scenarios, as these are typically smaller tables, it loads them from ooffice.
These two files must be saved from the openoffice input file with semicolon as field delimitor and no quotes for text.
