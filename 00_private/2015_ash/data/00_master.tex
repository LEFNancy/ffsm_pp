\begin{abstract}
This book contains the complete results of FFSM++ (ash project) in terms of tables and charts, hierarchically organised by region and theme.

Tables present a comparison (either at 2100 or as average of 2007-2100) between a reference scenario and a comparing one. If the latter one is a random scenario run multiple times some basic statistic is given.

On the other side charts provide a quick overview of the dynamic of key variables over time.

This document is generated automatically trough a script directly from the model's output. Please refer to the article for model description, scenario definition and output analysis.

\end{abstract}
